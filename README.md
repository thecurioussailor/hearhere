# HearHere

A Chrome extension (Manifest V3) that reads text on any web page out loud.

- **Select → Read:** highlight text and a **🔊 Read** button appears next to it.
- **Hover Read:** turn it on, then rest your cursor on a paragraph for about half a second. The paragraph gets highlighted and read aloud. Move to another paragraph to switch.
- **Playback controls:** an on-page player bar and the toolbar popup both have play/pause, stop and speed (0.75× to 2×). You can change speed while it's reading.
- **Keyboard shortcuts** (change them at `chrome://extensions/shortcuts`):

  | Action | Default |
  |---|---|
  | Read selection (or the paragraph under the cursor) | `Alt+Shift+R` (`⌥⇧R` on Mac) |
  | Pause / resume (starts reading if nothing is playing) | `Alt+Shift+Space` |
  | Stop | `Alt+Shift+S` or `Esc` |
  | Toggle Hover Read | `Alt+Shift+H` |

- Bonus: right-click selected text and choose **Read aloud with HearHere**.

## Install (developer mode)

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this folder (the one with `manifest.json`).
4. Pin HearHere to the toolbar. Tabs you already had open work right away, no reload needed.

After editing the code, click the ↻ reload icon on the HearHere card in `chrome://extensions`.

## How it's built

```
manifest.json
src/background.js   speech engine (chrome.tts), the reading session, shortcuts, context menu
src/content.js      selection button, hover detection and highlight, on-page player bar (Shadow DOM)
src/content.css     highlight styles injected into pages
popup/              toolbar popup: controls, speed, Hover Read toggle, voice picker, shortcuts
icons/              generated by scripts/make_icons.py
```

- Speech goes through **`chrome.tts`** in the service worker, not `speechSynthesis` in the page. Page CSP can't block it, it doesn't need a click on the page first (hover and shortcuts need that), and it keeps playing on a single session across the page.
- Text is split into sentence-sized chunks. That makes pause, stop and speed changes respond instantly and avoids voices that cut off long text. A speed change restarts the current sentence at the new speed.
- Hover detection walks up from the element under the cursor to the nearest readable block. That's a `p`, `li`, heading, `blockquote`, table cell and so on, or a block-level `div` whose text lives in inline children, which covers React-style markup.
- Settings (`rate`, `voiceName`, `hoverMode`) live in `chrome.storage.sync`.

## Known limitations (MVP)

- It doesn't work on `chrome://` pages, the Chrome Web Store or Chrome's built-in PDF viewer, because Chrome blocks extensions there.
- It only runs in the top frame. Text inside iframes (some embedded editors and comment widgets) isn't detected.
- Which voices you get depends on your OS. On macOS, you can install better voices under System Settings → Accessibility → Spoken Content.
