About your keys

Keys are stored only on this computer (chrome.storage.local, not synced). They are sent only to the provider's own API, from the extension, never to the web pages you visit. They are stored unencrypted, like in any browser extension, so use a key you can revoke, and set a spending limit in your provider's dashboard.
